# Compliance review aid — not certification
| Area | MVP control | Required review |
|---|---|---|
| DPDP Act 2023 / Rules | Consent gate, minimal fields, no raw audio | Counsel to review purpose notice, rights, retention, deletion, processors and breach response |
| RBI Digital Lending Directions 2025 | No autonomous decisions, synthetic products, illustrative disclaimer, escalation | Lender compliance team to review applicability, KFS/APR, LSP roles and grievance redressal |
| Access control | Staff dashboard/API for local demo | Add SSO/OIDC, RBAC and audit review before any real use |
| Data retention | Local JSONL audit and in-memory queue | Add configured retention and deletion |
| Calculations | Decimal EMI, product-derived rate/method, tests | Validate methodology and disclosures with lender/legal teams |
| Evidence | Approved status/effective-date filtering and source IDs | Add production document ingestion, conflict detection and hybrid retrieval |
